1. utworzenie w pliku taks.py  w katalogu api zadania hello world, które wypisuje w konsoli workera Hello from Celery!

from celery import shared_task

@shared_task
def hello_world():
    print("Hello from Celery!")

2. stworzenie widoku w Django, który po wejściu na odpowiedni adres URL wykona zadanie w api/views.py:

from django.http import HttpResponse

from .tasks import hello_world


def hello_celery(request):
    hello_world.delay()

    return HttpResponse("Zadanie Celery zostało wysłane.")


3. dodanie ścieżki w urlpatterns w api/urls.py:

from django.urls import path

from . import views


urlpatterns = [
    path("hello/", views.hello_celery),
]


4. dodanie ścieżki w config/urls.py:

from django.contrib import admin
from django.urls import include, path

urlpatterns = [
    path('admin/', admin.site.urls),
    path("", include("api.urls"))
]
