1. dodanie w config/settings.py importu:

from datetime import timedelta

2. dodanie harmonogramu Celery Beat:

CELERY_BEAT_SCHEDULE = {
    "log-timestamp-every-10-seconds": {
        "task": "api.tasks.log_timestamp",
        "schedule": timedelta(seconds=10),
    },
}

3. uruchomienie workera Celery:

python -m celery -A config worker -l info --pool=solo

4. uruchomienie Celery Beat w drugim terminalu:

python -m celery -A config beat -l info

5. Celery Beat rozpoczął automatyczne wysyłanie zadania co 10 sekund:
