14. utworzenie pliku celery.py w katalogu config z zawartością:

import os

from celery import Celery


os.environ.setdefault(
    "DJANGO_SETTINGS_MODULE",
    "config.settings",
)

app = Celery("config")

app.config_from_object(
    "django.conf:settings",
    namespace="CELERY",
)

app.autodiscover_tasks()

15. modyfikacja __init__.py  w katalogu config:
