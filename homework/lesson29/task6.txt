1. dodanie w config/settings.py importu:

from celery.schedules import crontab

2. dodanie do CELERY_BEAT_SCHEDULE zadania uruchamianego codziennie o godzinie 23:00:

"count-users-every-day-at-23": {
    "task": "api.tasks.count_users",
    "schedule": crontab(hour=23, minute=0),
},

3. do testu działania harmonogramu godzina została chwilowo ustawiona na najbliższą minutę, ponieważ Celery Beat został uruchomiony już po godzinie 23:00.

4. uruchomienie Celery Beat:

python -m celery -A config beat -l info

5. wynik:

celery beat v5.6.3 (recovery) is starting.

LocalTime -> 2026-08-09 23:12:42

[2026-08-09 23:12:42,359: INFO/MainProcess] beat: Starting...

[2026-08-09 23:12:43,007: INFO/MainProcess]
Scheduler: Sending due task count-users-every-day-at-23 (api.tasks.count_users)

6. po sprawdzeniu działania harmonogram przywrócono do wartości docelowej:

"schedule": crontab(hour=23, minute=0),

Celery Beat poprawnie uruchamia zadanie zgodnie z harmonogramem crontab.
