1. w api/views.py rozszerzono klasę class ProductViewSet(ModelViewSet) o metodę perform_update():

@method_decorator(cache_page(600), name="list")
@method_decorator(cache_page(60), name="retrieve")
class ProductViewSet(ModelViewSet):
    queryset = Product.objects.all()
    serializer_class = ProductSerializer

    def perform_update(self, serializer):
        product = serializer.save()

        cache.clear()

        return product

2. dodanie nowego produktu w celu przetestowania działania aplikacji:

POST http://127.0.0.1:8000/api/products/

Body  -> raw -> JSON:

{
     "name": "Komputer IBM PC",
    "price": 5500.00
}
